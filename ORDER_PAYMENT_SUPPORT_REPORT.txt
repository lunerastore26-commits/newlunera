IMPORTANT LIMITATIONS — PLEASE READ
1. This is still a static GitHub Pages website. Orders saved to localStorage exist only in the browser/device that placed the order. They are not a central cloud order database and will not automatically appear on another device.
2. EmailJS delivery has not been verified against the live EmailJS account from this package-building environment. Confirm that service_26ob5sw and template e00x0gi are active, that the template recipient is lunerastore26@gmail.com, and that it uses the template variables below. If the email fails, checkout still confirms the locally saved order and displays a warning.
3. No real online payment is collected or verified. The order is marked payment pending. Do not mark an order paid based only on a browser redirect or customer screenshot.
4. Admin/manage pages remain locked or limited until server-backed authentication is connected. Browser-only passwords and localStorage are not secure for customer order administration.
5. Do not use localStorage as the only production order record. Before taking real public orders at scale, connect a backend/database, server-side email sending, secure admin authentication, and a verified payment gateway if online payment is needed.
